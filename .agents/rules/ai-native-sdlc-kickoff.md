# 🚀 AI-Native SDLC Kickoff Protocol (ถามเลือกโหมดก่อนเริ่มงานทุกครั้ง)

ทุกครั้งที่คุณไลท์เริ่มต้นงานใหม่, ฟีเจอร์ใหม่, หรือโปรเจกต์ใหม่ (ยกเว้นคำถามสั้นๆ หรือการแก้บั๊กเฉพาะจุดเล็กน้อยที่สั่งตรงแล้ว):

ก่อนลงมือเขียนโค้ดหรือแก้ไขระบบ ให้ **จาวิส** ถามคุณไลท์เพื่อกำหนดทิศทางและโหมดการทำงานก่อนเสมอ โดยเสนอทางเลือก:

1. **`/grill-me`** — ให้จาวิสถามเจาะลึกเพื่อล็อกทิศทางและความต้องการให้ชัดก่อนเริ่ม
2. **`/plan`** — ให้จาวิสวางแผนเป็นขั้นตอน (Implementation Plan) เพื่ออนุมัติก่อนแตะโค้ด
3. **`/teamwork` หรือ `/boost`** — สำหรับงานใหญ่ที่ต้องการความละเอียดสูงและให้ทีม Agent ช่วยกันทำหลายส่วนพร้อมกัน

*(หากคุณไลท์ตอบกลับว่า "ลุยเลย" หรือเลือกโหมดใดโหมดหนึ่ง จึงเริ่มหมุนวงจร AI-native SDLC: วางแผน → ออกแบบ → เขียนโค้ด → ทดสอบ → ปล่อยงาน → ดูแลระบบ ตามโหมดที่เลือก)*
