Cybersecurity & IAM

2. Passly Vault — Password Manager (Pass App)

ระบบคลังจัดเก็บรหัสผ่านองค์กรด้วยสถาปัตยกรรม Zero-Knowledge ถอดรหัสภายในเครื่องด้วย AES-GCM 256-bit และ PBKDF2 600,000 รอบ พร้อมระบบส่งมอบรหัสผ่านชั่วคราวผ่านแชตบอต LINE และ Lark Suite

Zero-Knowledge: เซิร์ฟเวอร์ไม่เคยเห็นรหัสผ่านจริง บันทึกเฉพาะ Encrypted Envelope
Passly Secure Share: ส่งลิงก์ชั่วคราวและ PIN แยก 2 ข้อความผ่าน LINE/Lark
Privacy Shield ป้องกันการแคปหน้าจอ และ Optimistic Revision Lock ซิงก์ข้ามเครื่อง
AES-256 GCM PBKDF2 Node.js PostgreSQL LINE Bot Lark Suite

WebRTC P2P Real-Time

3. Organization Remote Support (Remote)

ระบบรีโมตซัพพอร์ตความปลอดภัยสูงสำหรับ Windows และ macOS ข้ามไฟร์วอลล์และ NAT ผ่าน WebRTC P2P พร้อมระบบสลับ TURN Relay อัตโนมัติ โดยเน้นความปลอดภัยแบบ Consent-First แยกสิทธิ์การควบคุมตามการยินยอม

สตรีมหน้าจอความหน่วงต่ำมาก (Ultra-low Latency) ด้วย WebRTC Media Stream
Consent-First: ควบคุมเมาส์/คีย์บอร์ด, คลิปบอร์ด, และไฟล์ (<25MB) ต้องได้รับอนุญาต
Emergency Disconnect ทันทีด้วยคีย์ลัด Ctrl+Alt+Shift+Esc
WebRTC WebSocket COTURN (TURN) TLS 1.3 Desktop Agent

FinTech & Thai Tax ERP

4. Thai Accounting System (ระบบบัญชี)

ระบบบริหารจัดการบัญชีและการเงินตามมาตรฐานการบัญชีและกรมสรรพากรไทย รองรับผังบัญชี 5 หมวด ออกใบรับรองแทนใบเสร็จรับเงิน คำนวณภาษีหัก ณ ที่จ่าย และกระทบยอดธนาคารโดยอัตโนมัติ

ผังบัญชี 5 หมวดและสมุดรายวันทั่วไป (General Journal) สองด้านเดบิต-เครดิต
ระบบออกใบรับรองแทนใบเสร็จรับเงินตามแบบฟอร์มกรมสรรพากร (พิมพ์ PDF)
คำนวณและออกรายงานภาษีอัตโนมัติ (ภ.ง.ด. 3, ภ.ง.ด. 53, และ ภ.พ. 30)
